# Project Instructions

## Testing UI Changes

When testing UI changes, use the Playwright CLI (e.g., `npx playwright test`, `npx playwright test --ui`, `npx playwright show-report`). Do not rely solely on code inspection — verify visual/interactive changes through Playwright.
